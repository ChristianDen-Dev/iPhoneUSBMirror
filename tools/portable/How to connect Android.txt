Den-Dev Live - Android
======================
WHAT IS IN THIS FOLDER
  DenDevLive.apk     the Den-Dev Live app for Android (same app as on the iPhone)

WHAT YOU NEED IT FOR (same as the iPhone app)
  USB mirror to the laptop   -> the app (picture + game sound + your mic)
  Wi-Fi mirror to the laptop -> the app
  Go Live from the phone     -> the app (Facebook / YouTube / TikTok / RTMP,
                                Studio look, floating comments over the game)

INSTALL THE APP (about 1 minute)
  1. Copy DenDevLive.apk to the phone (USB cable, Google Drive, Messenger...)
     or download it on the phone from the Google Drive link.
  2. Tap the file -> Android asks "Install unknown apps?" ->
     Settings -> allow for this app (Files / Chrome / Drive) -> back -> Install.
  3. Play Protect may say "unknown app": tap "More details" -> "Install anyway".
     (The app is not on the Play Store; it is safe and open source.)
  4. Open Den-Dev Live. Allow Microphone and Notifications when asked.
     For floating comments: tap "Allow" (Display over other apps).
  New version later: install the new APK the same way, over the old one.

USB MIRROR - ONE TIME ON THE PHONE (turn on USB debugging)
  1. Settings -> About phone -> tap "Build number" 7 times.
     (Samsung: Settings -> About phone -> Software information -> Build number.)
     It says "You are now a developer".
  2. Settings -> Developer options (or System -> Developer options)
     -> USB debugging -> ON.

USB MIRROR - EVERY TIME
  1. Start Den-Dev Live on the laptop (Desktop shortcut).
  2. Plug in the phone. On the phone: "Allow USB debugging?"
     -> tick "Always allow from this computer" -> Allow.
  3. App -> USB -> Start mirroring -> "Entire screen" -> Start now.
  4. The phone screen + game sound appear on the laptop. The mouse works as
     your finger. Backspace = Back, Home = Home, End = Recent apps.
     Your mic: switch "Your mic to the stream" ON in the app (or the bubble).
  If the cable blinks, the mirror keeps running on the phone and the laptop
  reconnects by itself in about 1 second.
  (Without tapping Start mirroring the laptop still shows the screen, but
  without your mic, and a cable blink takes longer to recover.)

WI-FI MIRROR (with the app)
  Phone and laptop on the same Wi-Fi. App -> Wi-Fi -> Start mirroring ->
  Start now. The laptop finds the phone by itself (press W to search now).

GO LIVE (with the app)
  App -> Go Live -> platform -> paste the stream key -> GO LIVE -> Start now.
  Tap the floating bubble for comments + Mic / Screen / Stop buttons;
  tap the game to hide them. First test with privacy "Only me".

SOUND
  Game sound needs Android 10 or newer (USB mirror: Android 11+), and the game
  must allow sound recording. Game voice chat (teammates) cannot be recorded
  by any app on Android.

PROBLEMS
  - Phone not found by USB: try another cable / USB port, set the USB mode to
    "File transfer", or install the phone maker's USB driver.
  - Cable keeps dropping: Developer options -> Default USB configuration ->
    File transfer; plug straight into the laptop (no hub); use a data cable.
  - No "Allow USB debugging" message: unplug, turn USB debugging off and on, plug in.
  - "App not installed": uninstall the old Den-Dev Live first, then install again.
