Den-Dev Live - Android
======================
NOTHING TO INSTALL ON THE PHONE.
The laptop program sends a small helper to the phone through the cable every
time it connects (the same way the well-known open-source tool "scrcpy" works).
When you unplug, the helper is gone. No app, no APK.

ONE TIME ON THE PHONE (turn on USB debugging)
  1. Settings -> About phone -> tap "Build number" 7 times.
     (Samsung: Settings -> About phone -> Software information -> Build number.)
     It says "You are now a developer".
  2. Settings -> Developer options (or System -> Developer options)
     -> USB debugging -> ON.

CONNECT BY CABLE
  1. Start Den-Dev Live on the laptop (Desktop shortcut).
  2. Plug in the phone. On the phone: "Allow USB debugging?"
     -> tick "Always allow from this computer" -> Allow.
  3. The phone screen appears on the laptop. The mouse works as your finger.
     Backspace = Back, Home = Home, End = Recent apps.

CONNECT BY WI-FI (after the cable works once)
  Right-click the Den-Dev Live window -> "Android: switch to Wi-Fi" ->
  unplug. Do it again after each phone restart.

SOUND
  Needs Android 11 or newer. While mirroring, the phone speaker is silent;
  right-click -> "Android: keep game sound on the phone too" (Android 13+).

PROBLEMS
  - Phone not found: try another cable / USB port, set the USB mode to
    "File transfer", or install the phone maker's USB driver.
  - No "Allow USB debugging" message: unplug, turn USB debugging off and on, plug in.
  - Go Live directly from the phone (without the laptop) is iPhone-only for now.
