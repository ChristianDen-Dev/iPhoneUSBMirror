Den-Dev Live — Setup Guide

Mirror an iPhone or Android phone to a Windows PC (USB or Wi-Fi) for OBS / TikTok LIVE Studio, or go live straight from the iPhone.

1. Download2. PC setup3. iPhone 4. Android5. Use itGo LiveProblems

PC 1. Download from Google Drive

  1. Open the Google Drive link and download the zip for your phone: DenDevLive_iPhone.zip (about 270 MB) or DenDevLive_Android.zip (about 120 MB). Both have the same laptop program.
    Google says "can't scan this file for viruses" because it is big → click Download anyway.
  2. In the Downloads folder: right-click the zip → Properties → tick Unblock → OK. (If there is no Unblock box, that is fine.) This stops Windows from blocking the program later.
  3. Right-click the zip → Extract All → choose a simple place, for example C:\DenDevLive.
    Do not run it from inside the zip, and not from a OneDrive / Google Drive sync folder.
Needs Windows 10 or 11, 64-bit. No Python or other install is needed for the mirror itself. (Mac and Linux are not supported.)

PC 2. First-time setup on each PC

  1. Open the extracted folder → 1 - LAPTOP → double-click 1 - SETUP (first time).bat.
    If Windows says "Windows protected your PC" → More info → Run anyway.
  2. It checks the PC and shows [OK] or [!] for each part. For anything missing it asks Y/N — type Y to install it:
    Apple DevicesOnly for iPhone by cable and for Sideloadly. Opens the Microsoft Store → Get.
    SideloadlyOnly to put the app on an iPhone (and renew it every 7 days).
    VB-Audio CableOnly for streaming the sound in OBS / TikTok. Needs a PC restart after.
  3. Say Y to the Desktop shortcut. From now on start the mirror with Den-Dev Live on the Desktop (or 1 - LAPTOP\2 - Start Den-Dev Live.bat).
  4. If Windows Firewall asks about python or adb: Cancel is fine (the mirror does not need it).

iPhone 3. Put the Den-Dev Live app on the iPhone

Apple does not allow apps from outside the App Store without these steps. You do them once per iPhone (and renew every 7 days with a free Apple ID).

  1. Plug the iPhone into the PC with the cable. Unlock it and tap Trust → type the iPhone passcode.
  2. Open Sideloadly. Drag 2 - iPHONE\DenDevLive.ipa into it.
  3. Type your own Apple ID e-mail and click Start. Type your password (and the 6-digit code) only in Sideloadly. Never give your Apple ID password to anyone. Wait for "Done".
  4. Trust the app on the iPhone: Settings → General → VPN & Device Management → tap your Apple ID → Trust → Trust.
  5. Developer Mode (iOS 16 and newer): Settings → Privacy & Security → Developer Mode → ON → the iPhone restarts → after unlock tap Turn On. (The switch appears only after step 3.)
  6. Open Den-Dev Live. For Wi-Fi it asks "find devices on your local network" → Allow.
  7. Recommended: Settings → Control Center → add Screen Recording (quick start/stop), and turn on Do Not Disturb while streaming.
Every 7 days (free Apple ID) the app stops opening. Just repeat steps 1–3 — settings and stream key stay. If you see "maximum number of apps", delete old sideloaded apps first.

Android 4. Android phone (no app to install)

  1. Settings → About phone → tap Build number 7 times (Developer options turn on).
    Xiaomi: MIUI version; Samsung: Software information → Build number.
  2. Settings → Developer options → USB debugging ON. (Xiaomi also: USB debugging (Security settings) ON to allow touch control.)
  3. Plug into the PC, start the mirror, then on the phone tap Allow and tick Always allow from this computer.
  4. Wireless: while it is on the cable, right-click the mirror → Android: switch to Wi-Fi, then unplug.
Sound needs Android 11 or newer. If the phone is not found: try another cable / USB port, choose USB mode File transfer, or install your phone maker's USB driver.

PC 5. Mirror and stream

iPhone by cable (lowest delay)Start the mirror on the PC → iPhone: Den-Dev Live → USB → Start mirroring → Start Broadcast.
iPhone by Wi-FiSame Wi-Fi (5 GHz best) or PC on the iPhone Hotspot → Den-Dev Live → Wi-Fi → Start mirroring. Press W on the PC to search now.
AndroidPlug in (or Wi-Fi) — it appears by itself. Mouse = finger.

OBS / TikTok LIVE Studio

PictureWindow Capture → [python.exe]: Den-Dev Live (Capture Audio OFF). Press F2 for Stream Mode.
SoundDesktop Audio = CABLE Input. Mic/Aux = Disabled (the mirror already mixes game + mic).

Keys: F2 Stream Mode · F11 full screen · F9 record · F12 screenshot · M PC sound · V stream mic · L USB / Wi-Fi / Auto · H all keys · right-click = menu.

iPhone Go Live without a PC

  1. Get your stream key: Facebook → facebook.com/live/producer → Streaming software → "Use a persistent stream key" → copy. YouTube → Studio → Go live → Stream → copy.
  2. Den-Dev Live → Go Live → choose the platform → paste the key → pick quality.
  3. Sound card: Den-Dev Live mic (game stays loud) = ON.
  4. Tap GO LIVE → keep Microphone OFF (grey) in the Start Broadcast sheet → Start Broadcast → open your game. The app records your voice itself, so iOS does not turn the game sound down. Teammates' voices are part of the game sound.
  5. Comments: tap the arrow tab (drag it to any side) → see-through comments float over the game; tap the game to hide them. Sign in once in Full chat. Screen hidden = viewers see "Be right back"; Mic off mutes you.
  6. Studio (Go Live → Studio): landscape / portrait, fit / blur / fill, your logo, banner text, LIVE badge. Changes show on the live within 1 second.
First test with Facebook privacy Only me. The stream key is a secret — never share it or put it in a screenshot.

Help Problems

ProblemFix
"Windows protected your PC"More info → Run anyway. Or Unblock the zip before extracting (step 1).
Smart App Control blocks a fileDelete the folder, Unblock the zip, extract again. Still blocked: Windows Security → App & browser control.
Sideloadly does not see the iPhoneInstall Apple Devices (SETUP), unplug/replug, unlock, tap Trust. Try another cable/port. Older Windows: iTunes from apple.com.
App will not open on the iPhoneTrust it (VPN & Device Management) and turn on Developer Mode. After 7 days: install again with Sideloadly.
"Waiting for a phone"Start the broadcast on the iPhone / tap Allow on Android. Wi-Fi: press W, same Wi-Fi, Local Network = Allow.
Wi-Fi stuttersUse 5 GHz Wi-Fi or the iPhone Hotspot, or the USB cable.
No sound in OBSInstall VB-Cable (SETUP, then restart). Desktop Audio = CABLE Input. Press A in the mirror.
Go Live: game gets quiet when I talkTurn ON "Den-Dev Live mic" and keep Microphone OFF in the Start Broadcast sheet. (Talking in the game's own voice chat can still make the game a bit quieter — that is the game.)
Go Live: "trouble playing" / stopsCheck the internet (Wi-Fi or mobile data), the stream key and that the live is set up on the website. The app reconnects by itself.
Anything elseRun 1 - LAPTOP\1 - SETUP (first time).bat again — it shows what is missing.
