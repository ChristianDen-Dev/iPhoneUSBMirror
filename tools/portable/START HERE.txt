Den-Dev Live - portable package
====================================
Mirrors an iPhone OR an Android phone to this Windows PC, by USB cable or by
Wi-Fi, with game sound, for OBS / TikTok LIVE Studio. No time limit, no
watermark. Nothing to install for the mirror itself.


EASIEST: open  "START HERE (guide).html"  (any browser, also on the phone).


WHAT IS IN THIS FOLDER
  1 - SETUP (first time).bat   run once on each new PC: checks it, offers to
                               install what is missing, makes a Desktop shortcut
  2 - Start Mirror.bat         starts the mirror (or the Desktop shortcut)
  START HERE (guide).html      the full illustrated guide
  app\  python\                the program and its own Python (touches nothing)
  installers\                  Sideloadly, VB-Cable, the iPhone app (.ipa)


FIRST TIME ON A NEW PC (about 5 minutes)
  1. Downloaded from Google Drive? Right-click the ZIP -> Properties ->
     tick "Unblock" -> OK. Then right-click -> Extract All -> C:\iPhoneUSBMirror
     (not inside a OneDrive / Google Drive sync folder, not inside the zip).
  2. Double-click  "1 - SETUP (first time).bat" .
     "Windows protected your PC" -> More info -> Run anyway.
     Type Y for what you need:
       Apple Devices  - iPhone by USB cable + Sideloadly
       Sideloadly     - to put the app on an iPhone
       VB-Audio Cable - stream sound to OBS / TikTok (restart the PC after)
  3. Start with the Desktop shortcut "Den-Dev Live".
     If the Firewall asks about python or adb: Cancel is fine.


IPHONE
  The "Den-Dev Live" app must be on the iPhone (installed with Sideloadly).
  USB : plug in, unlock, tap Trust if asked.
  Wi-Fi: iPhone and PC on the SAME Wi-Fi (5 GHz is best), or connect the PC
         to the iPhone's Personal Hotspot. The first time, the iPhone asks
         "find devices on your local network" -> Allow.
  Then: open Den-Dev Live on the iPhone -> tap USB or Wi-Fi -> Start mirroring
        -> Start Broadcast. The picture appears by itself (W = search Wi-Fi now).
  First toolbar button (or L) chooses the connection:
    Auto = cable when plugged in, otherwise Wi-Fi  |  USB only  |  Wi-Fi only
  USB has the lowest delay. In Auto, plugging the cable in while on Wi-Fi
  switches to USB by itself.

  Free Apple ID: the app stops opening after 7 days. Re-install it:
    1. Stop the broadcast on the iPhone.
    2. Sideloadly + Apple Devices must be installed (SETUP does it).
    3. Plug in the iPhone, drag installers\iPhoneUSBMirror.ipa into Sideloadly,
       type YOUR Apple ID, Start. Type the password yourself in Sideloadly only.
    4. iPhone: Settings > General > VPN & Device Management > trust your Apple ID.
    5. First time only (iOS 16+): Settings > Privacy & Security > Developer Mode
       ON -> restart -> Turn On.


GO LIVE FROM THE IPHONE (no PC)
  Den-Dev Live -> Go Live -> platform -> paste your stream key -> GO LIVE.
  Arrow tab on the right edge = comments (tap again to hide).
  "Screen hidden" = viewers see Be right back. Test with privacy "Only me".


ANDROID (no app to install on the phone)
  One time on the phone:
    Settings > About phone > tap "Build number" 7 times (Developer options ON)
    Settings > Developer options > USB debugging ON
  USB : plug in -> on the phone tap "Allow USB debugging"
        (tick "Always allow from this computer").
  Wi-Fi: first connect by USB, then right-click the mirror -> "Android: switch
         to Wi-Fi", then unplug. (Again after each phone restart.)
  The mouse works as your finger. Backspace = Back, Home = Home, End = Recent apps.
  Sound needs Android 11 or newer. By default the phone speaker is silent while
  mirroring; right-click -> "Android: keep game sound on the phone too" (Android 13+).
  If the phone is not found by USB: try another cable/port, set USB mode to
  "File transfer", or install the phone maker's USB driver.


OBS / TIKTOK LIVE STUDIO
  Picture : Window Capture -> "[python.exe]: Den-Dev Live" (Capture Audio OFF).
            Press F2 in the mirror for Stream Mode (clean picture, exact size).
  Sound   : Desktop Audio = CABLE Input (VB-Audio Virtual Cable). Mic/Aux = Disabled.
            The mirror already mixes game sound + your mic into the cable.
  M mutes only the PC speakers - the stream keeps the sound.
  V chooses the stream mic (Auto / Laptop / iPhone / none).


KEYS
  F2 Stream Mode   F11 fullscreen   F12 screenshot   F9 record   M laptop sound
  A sound panel    V stream mic     N mute mic       W find iPhone on Wi-Fi
  L or the first toolbar button = connection: Auto / USB only / Wi-Fi only
  H all keys       Right-click = all options


PROBLEMS
  - Black window, "Waiting for a phone": start the broadcast (iPhone) /
    tap Allow (Android). For Wi-Fi press W.
  - iPhone by USB not found: install Apple Devices (run SETUP), unplug/replug, unlock.
  - Stutters on Wi-Fi: use 5 GHz Wi-Fi or the iPhone Hotspot, or use the USB cable.
  - Smart App Control blocks a file: Windows Security > App & browser control.
  - No sound in OBS: Desktop Audio must be CABLE Input; press A in the mirror.
